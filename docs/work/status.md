> - **4. PR 생성 완료**: `[GitManager] [기능명] PR 생성 완료 (PR #nn) ➔ qa에게 검수 인계`
> - **5-A. QA 진행 중**: `[QA] [기능명] QA 4대 검수 진행 중 (NUnit, 콘솔, 코어루프, 스크린샷)`
