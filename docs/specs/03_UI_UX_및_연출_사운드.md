# [03] UI / UX 및 연출, 사운드 (UI/UX, Visual & Audio)

## 1. 화면 규격 및 HUD 레이아웃 (Screen & HUD)

### 1.1 기본 해상도 및 종횡비
* **기준 해상도**: 224 x 288 px (원작 아케이드 기준 3:4 세로형 화면)
* **모던 디스플레이 대응**:
  * 16:9 와이드 화면 지원 시: 중앙 3:4 게임 뷰 배치 및 좌우 필러박스(Pillarbox)에 일러스트/조작 가이드/실시간 통계 배치.
  * 모바일/세로형 디스플레이: 전체 세로 화면(Portrait View) 전폭 활용.

### 1.2 HUD (헤드업 디스플레이) 레이아웃 구성

```
┌──────────────────────────────────────────────┐
│  1UP         HIGH SCORE           2UP        │ ◄-- 최상단 스코어보드 (Y: 0~16px)
│  002400        035000            000000      │
├──────────────────────────────────────────────┤
│                                              │
│                                              │
│               [ 주 게임 화면 ]               │
│             (우주 별 배경 스크롤)            │
│                                              │
│               [ 적 편대 40기 ]               │
│                                              │
│                                              │
│                                              │
│                                              │
│                                              │
│             ▲  ▲                             │
│          [ 플레이어 기체 ]                   │
├──────────────────────────────────────────────┤
│  ▲ ▲                                  ⚑ ⚑ ⭐ │ ◄-- 최하단 상태창 (Y: 272~288px)
│ [잔여 기수]                        [스테이지 뱃지]│
└──────────────────────────────────────────────┘
```

* **상단 영역 (Top HUD)**:
  * `1UP`: 1P 현재 점수 (실시간 갱신)
  * `HIGH SCORE`: 최고 점수 (실시간 갱신 및 신기록 시 깜빡임)
  * `2UP`: 2P 대기 점수 (2인 턴제 모드 시)
* **하단 좌측 영역 (Bottom-Left HUD)**:
  * 대기 중인 잔여 파이터 기체 아이콘 (최대 5기까지 표시, 초과 시 숫자로 보정).
* **하단 우측 영역 (Bottom-Right HUD)**:
  * 현재 스테이지를 상징하는 **스테이지 뱃지(Stage Badge)** 아이콘 나열.

## 2. 스테이지 뱃지 표기 시스템 (Stage Badges)

화면 하단 우측의 공간을 효율적으로 사용하기 위해 스테이지 번호를 조합형 뱃지로 표시합니다.

| 뱃지 종류 | 가치 (Stage Value) | 아이콘 형태 / 색상 | 표기 규칙 |
| :--- | :---: | :--- | :--- |
| **청색 리본 (Ribbon)** | **1** | 청색 1줄 리본 | 1~4 스테이지 표기 |
| **적색/황색 쉐브론** | **5** | 황색/적색 꺾쇠 엠블럼 | 5 스테이지 단위 |
| **대형 별 (Star)** | **10** | 청색 테두리 백색 대형 별 | 10 스테이지 단위 |
| **적색/황색 대형 별** | **20** | 황색/적색 대형 별 | 20 스테이지 단위 |
| **청색 깃발 (Flag)** | **30** | 청색 역삼각 깃발 | 30 스테이지 단위 |
| **금색 깃발 (Gold Flag)**| **50** | 금색/주황색 대형 깃발 | 50 스테이지 단위 |

> **예시**:
> * Stage 3 = 청색 리본 3개
> * Stage 8 = 쉐브론(5) 1개 + 청색 리본(1) 3개
> * Stage 37 = 깃발(30) 1개 + 쉐브론(5) 1개 + 청색 리본(1) 2개

## 3. 시각 연출 및 비주얼 이펙트 (Visual Effects)

### 3.1 우주 배경 패럴랙스 스크롤 (Parallax Starfield)
* **3단계 깊이감 레이어**:
  * Layer 1 (원경): 작은 크기(1px) 별, 청색/어두운 회색, 느린 스크롤 속도 (15 px/sec).
  * Layer 2 (중경): 중간 크기(1~2px) 별, 노란색/백색, 중간 스크롤 속도 (30 px/sec).
  * Layer 3 (근경): 큰 크기(2px) 별, 밝은 백색/적색 깜빡임, 빠른 스크롤 속도 (60 px/sec).
* 스테이지 클리어 및 다이브 시 배경 스크롤 속도를 일시적으로 가속하여 공간 이동 연출.

### 3.2 트랙터 빔 연출 (Tractor Beam Effect)
* 보스 갤러그 하단에서 원뿔형(Trapezoid) 빔 프로젝션.
* 파란색, 하늘색, 흰색이 교차하는 사이클링 물결 셰이더/스프라이트 루프.
* 기체 흡수 시 기체가 회전하며 중심선으로 빨려 들어가는 보간 애니메이션.

### 3.3 폭발 및 파괴 파티클 (Explosions)
* **자코/고에이 폭발**: 4프레임 방사형 원형 폭발 스프라이트 + 링 파티클 확산.
* **보스 갤러그 폭발**: 1차 타격 시 청색 플래시 / 2차 타격 시 대형 복합 폭발 + 파편 비산.
* **플레이어 폭발**: 중심에서 사방으로 퍼지는 8방향 십자 불꽃 파티클 (약 1.0초 지속).

### 3.4 결과 화면 (Game Over Results Screen)
게임 오버 후 중앙 화면에 출력되는 통계 UI:

```
    - - - - RESULTS - - - -
    
    SHOTS FIRED         1250
    NUMBER OF HITS      0980
    HIT-MISS RATIO     78.4 %
```

## 4. 사운드 및 오디오 명세 (Audio & SFX)
