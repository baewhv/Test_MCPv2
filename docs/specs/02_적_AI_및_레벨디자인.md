# [02] 적 AI 및 레벨 디자인 (Enemy AI & Level Design)

| **고에이 (Goei)** | Guard / 적색 나비 | 1 | 16기 (중단 2열) | • 편대 중간 2열에 배치.<br>• 360도 공중제비(Loop) 기동을 하며 탄환을 하단으로 살포.<br>• 보스 갤러그의 호위기로 합류하여 협공 다이브. |

## 2. 적 AI 상태 머신 및 비행 궤적 (State Machine & Trajectories)

### 2.1 적 개체 라이프사이클 (State Machine)

```
[ 스폰 (Spawn) ] 
       │
       ▼
[ 편대 진입 (Entrance) ] ──(곡선 궤적 비행)──> [ 편대 안착 (Grid Slot) ]
                                                     │
                                                     ▼
                                            [ 편대 대기/호흡 (Hovering) ]
                                                     │
                                                     ▼
                                            [ 다이브 준비 (Dive Prep) ]
                                                     │
                                                     ▼
                                            [ 급강하 및 사격 (Diving Attack) ]
                                                     │
                     ┌───────────────────────────────┴───────────────────────────────┐
                     ▼                                                               ▼
        (화면 하단 통과하여 이탈)                                       (플레이어 기체 포획 성공)
                     │                                                               │
                     ▼                                                               ▼
        [ 화면 상단으로 재진입 (Re-entry) ]                             [ 포획기와 함께 편대 복귀 ]
                     │
                     ▼
        [ 편대 안착 (Grid Slot) ]
```

### 2.2 편대 진입 시퀀스 (Entrance Waves)
스테이지 시작 시 40기의 적은 아래 5개 그룹으로 나뉘어 순차적으로 등장합니다:
1. **Group 1 (8기)**: 상단 중앙에서 진입 → 보스 갤러그 4기 + 고에이 4기
2. **Group 2 (8기)**: 좌측 하단에서 진입하여 루프 선회 → 자코 8기
3. **Group 3 (8기)**: 우측 하단에서 진입하여 루프 선회 → 자코 8기
4. **Group 4 (8기)**: 좌측 상단에서 진입 → 고에이 8기
5. **Group 5 (8기)**: 우측 상단에서 진입 → 고에이 4기 + 자코 4기

### 2.3 비행 궤적 알고리즘 (Trajectory Mathematics)
* 적의 모든 비행 경로는 **3차 베지어 곡선(Cubic Bézier Curve)** 또는 **스플라인 웨이포인트(Spline Waypoints)** 기반으로 계산됩니다.
* $$B(t) = (1-t)^3 P_0 + 3(1-t)^2 t P_1 + 3(1-t) t^2 P_2 + t^3 P_3 \quad (0 \le t \le 1)$$
* 다이브 공격 시 목표 지점($P_2, P_3$)은 플레이어 기체의 현재 X좌표를 실시간으로 추적/예측하여 유연한 유도 곡선을 형성합니다.

### 2.4 적 탄환 발사 알고리즘
* **발사 타이밍**: 다이브 시작 후 궤적 진행도 $t = 0.3 \sim 0.6$ 구간(하강 가속 중)에서 1~2발 발사.
* **조준 벡터**: 적 위치에서 플레이어 기체 중심점을 향하는 단위 벡터 $(\Delta X, \Delta Y)$를 정규화하여 탄속 $V_{bullet}$을 곱해 발사.

## 3. 스테이지 구조 및 레벨 디자인 (Level Progression)

### 3.1 스테이지 순환 구조

| 스테이지 번호 | 스테이지 유형 | 특징 및 목표 |
| :---: | :---: | :--- |
| **Stage 1** | 일반 스테이지 | 튜토리얼 성격, 적 이동 속도 보통, 탄환 발사 빈도 낮음 |
| **Stage 2** | 일반 스테이지 | 트랙터 빔 사용 빈도 증가 |
| **Stage 3** | **챌린징 스테이지 1** | 보너스 라운드 (적 탄환 없음, 40기 전멸 도전) |
| **Stage 4 ~ 6** | 일반 스테이지 | 변신 적 등장 시작, 적 복합 편대 강하 |
| **Stage 7** | **챌린징 스테이지 2** | 고속 비행 궤적 적용 |
| **Stage 8 ~ 10** | 일반 스테이지 | 3기 동시 다이브 및 고속 조준탄 발사 |
| **Stage 11** | **챌린징 스테이지 3** | 교차 궤적 비행 패턴 |
| **... (이후 4주기)** | **일반 3회 + 챌린징 1회** | 무한 루프 진행 (매 스테이지마다 랭크 가산) |

### 3.2 챌린징 스테이지 (Challenging Stage) 상세 설계
* **특징**:
  * 적이 탄환을 전혀 발사하지 않으며 오직 비행 궤적만을 그리며 통과.
  * 플레이어는 피격 위험 없이 조준과 격파에만 집중 가능.
* **웨이브 구성**:
  * 총 5개 웨이브 x 각 8기 = 40기 출현.
  * Wave 1: 좌측 상단 진입 후 중앙 8자 선회.
  * Wave 2: 우측 상단 진입 후 중앙 8자 선회.
  * Wave 3: 좌측 하단 진입 후 상단 루프.
  * Wave 4: 우측 하단 진입 후 상단 루프.
  * Wave 5: 중앙 좌우 동시 교차 분할 진입.
* **클리어 보상**:
  * `격파 수 == 40`: 화면에 "PERFECT" 문구 표시 및 **10,000점** 보너스.
  * `격파 수 < 40`: "NUMBER OF HITS : XX" 표시 및 `XX * 100점` 지급.

## 4. 동적 난이도 조절 시스템 (Dynamic Rank System)

게임의 지루함을 방지하고 고수 유저에게 긴장감을 제공하기 위한 난이도 가변 공식입니다.

```
최종 난이도 랭크 (Rank) = BaseStageRank + PlayerSurvivalRank
```

| 파라미터 | Stage 1 (최저) | Stage 10 (중간) | Stage 20 이상 (최고) |
| :--- | :---: | :---: | :---: |
| **적 비행 속도 (px/sec)** | 120 | 180 | 250 |
| **동시 다이브 적 기체 수** | 최대 2기 | 최대 3기 | 최대 5기 |
| **적 탄환 탄속 (px/sec)** | 160 | 220 | 300 |
| **다이브 쿨타임 (초)** | 3.0초 | 1.8초 | 0.8초 |
| **보스 트랙터 빔 사용 빈도** | 낮음 | 보통 | 높음 |
| **플레이어 사망 시 랭크 보정** | - | 랭크 -2 즉시 하향 | 랭크 -3 하향 (최소 기준치 유지) |
