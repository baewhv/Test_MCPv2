# [00] 개요 및 핵심 루프 (Overview & Core Loop)

## 1. 프로젝트 개요

### 1.1 기본 정보
* **게임명**: 갤러그 (Galaga / ギャラガ)
* **장르**: 2D 종스크롤 고정 화면 아케이드 슈팅 (Fixed-screen Shoot 'em up)
* **시점**: 탑뷰 (Top-Down 2D)
* **원작 참조**: 1981년 Namco 발매 아케이드 게임 Galaga
* **테마**: 우주 공간에서 침략해오는 외계 곤충형 비행 편대(Galaga Corps) 요격

### 1.2 기획 의도 및 핵심 가치
1. **단순한 조작과 높은 몰입감**: 좌/우 이동과 단일 공격 버튼만으로 직관적인 아케이드 액션 제공.
2. **리스크 앤 리턴 (Risk & Return)의 정점**: 적의 트랙터 빔에 기체를 일부러 포획당한 뒤 구출하여 화력을 2배로 증강시키는 독창적인 '듀얼 파이터' 시스템.
3. **리듬감 있는 슈팅 쾌감**: 회전 및 곡선 궤적을 그리며 진입하는 적들을 예측 사격하여 격파하는 손맛.
4. **정밀한 기록 경쟁**: 스테이지 진행도, 점수, 그리고 게임 종료 후 산출되는 '명중률(Hit-Miss Ratio)'을 통한 반복 도전 유도.

## 2. 핵심 게임플레이 루프 (Core Gameplay Loop)

```
[ 게임 시작 (Start) ]
        │
        ▼
┌──────────────────────────────────────────────┐
│ 1. 편대 진입 단계 (Entrance Phase)          │
│  - 적들이 곡선 궤적으로 화면에 진입           │
│  - 진입 중인 적을 선제 요격하여 위험 감소    │
└──────────────────────┬───────────────────────┘
        │
        ▼
┌──────────────────────────────────────────────┐
│ 2. 편대 대기 및 급강하 단계 (Diving Phase)   │
│  - 적 편대 정렬 완료 및 좌우 흔들림          │
│  - 개별/소대 단위로 탄환 발사하며 급강하      │
│  - 보스 갤러그의 트랙터 빔 포획 기믹 대응    │
└──────────────────────┬───────────────────────┘
        │
        ▼
┌──────────────────────────────────────────────┐
│ 3. 스테이지 클리어 판정                       │
│  - 화면 내 모든 적 격파 시 다음 단계 이동     │
└───────┬──────────────────────────────┬───────┘
        │ (일반 스테이지)              │ (3, 7, 11... 스테이지)
        ▼                              ▼
┌──────────────────────┐      ┌──────────────────────────────┐
│ 일반 스테이지 진행   │      │ 챌린징 스테이지 (보너스)     │
│ (난이도 랭크 상승)   │      │  - 적 탄환 발사 X           │
│                      │      │  - 40기 전멸 시 보너스 획득  │
└──────────┬───────────┘      └──────────────┬───────────────┘
           │                                 │
           └────────────────┬────────────────┘
                            │
                            ▼
               [ 잔기(Life) 모두 소진 시 ]
                            │
                            ▼
               [ 게임 오버 및 결과 화면 ]
               - 최종 점수 (Score)
               - 발사 탄수 / 명중 탄수 / 명중률(%)
```

### 2.1 세부 단계 설명

#### Phase 1. 편대 진입 단계 (Entrance Phase)
* 스테이지 개시 시 상단 편대 자리가 비어 있는 상태에서 총 40기의 적이 5개 그룹(각 8기)으로 나뉘어 순차 진입합니다.
* 플레이어는 적이 상단에 배치되기 전에 이동 궤적을 예측하여 요격할 수 있습니다.
* 진입 중인 적을 많이 격파할수록 이후 강하 단계의 난이도가 대폭 감소합니다.

#### Phase 2. 대기 및 급강하 공격 단계 (Formation & Diving Phase)
* 진입을 마친 적들이 상단에서 좌우로 호흡하듯 진동하며 대기합니다.
* 주기적으로 자코, 고에이, 보스 갤러그가 단독 또는 호위기를 대동하고 하단 플레이어를 향해 선회/급강하합니다.
* 급강하 시 적 기체는 플레이어 조준 탄환을 발사합니다.
* 보스 갤러그는 하강 중 트랙터 빔을 발사하여 플레이어 기체를 포획할 수 있습니다.

#### Phase 3. 스테이지 클리어 및 루프 반복
* 화면에 남아있는 적 40기를 모두 섬멸하면 스테이지가 클리어됩니다.
* 클리어 시 화면 하단 우측에 스테이지 뱃지(Stage Badge)가 추가되고, 난이도 랭크(적 속도, 탄환 속도, 강하 빈도)가 상승합니다.

#### Phase 4. 챌린징 스테이지 (Challenging Stage / Bonus Stage)
* Stage 3, Stage 7, 이후 매 4스테이지마다(Stage 11, 15, 19, 23...) 챌린징 스테이지가 발생합니다.
* 총 40기의 적이 5개 웨이브(각 8기)로 정해진 곡선 궤적을 그리며 화면을 통과한 뒤 이탈합니다.
* 적은 탄환을 발사하지 않으며, 플레이어와 충돌 판정도 발생하지 않습니다(또는 회피할 필요 없이 사격에만 집중).
* 40기 완파(PERFECT) 시 대량의 보너스 점수(10,000점)를 지급합니다.

## 3. 핵심 차별화 요소 (Key Features)

### 3.1 듀얼 파이터 시스템 (Dual Fighter System)
* **개념**: 단일 기체(Single Fighter) 상태에서 보스 갤러그의 트랙터 빔에 일부러 잡힌 뒤(잔기 1 소모), 다음 잔기로 출격하여 포획기를 데리고 내려오는 보스를 격파해 2대의 기체를 합체시키는 시스템.
* **효과**:
  * 공격력 2배: 한 번 발사 시 미사일 2발 동시 발사 (화면 내 최대 4발 존재 가능).
  * 히트박스 2배: 좌우 피격 범위가 2배로 증가하여 피탄 위험성 상승.
  * 완벽한 하이 리스크-하이 리턴 밸런스 제공.

### 3.2 탄환 수량 제한 (Screen-limited Projectiles)
* 플레이어는 난사가 불가능하며, **화면 내에 발사된 미사일이 최대 2발(싱글) / 4발(듀얼)** 로 제한됩니다.
* 미사일이 화면 상단 끝까지 날아가 사라지거나 적에게 명중해야 다음 탄환을 발사할 수 있으므로, 적에게 근접할수록 연사 속도가 빨라지는 물리적 공간 메커니즘을 가집니다.

### 3.3 명중률 통계 (Hit-Miss Ratio)
* 게임 종료 시 총 발사 탄수(Shots Fired), 명중 탄수(Number of Hits), 명중률(Hit-Miss Ratio %)을 정밀 계산하여 출력함으로써 아케이드 게이머의 승부욕과 실력 지표를 제공합니다.
