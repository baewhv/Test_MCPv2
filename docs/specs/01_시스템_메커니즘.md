# [01] 시스템 메커니즘 (System Mechanics)

## 1. 플레이어 시스템 (Player System)

### 1.1 기본 조작 및 스펙
* **이동 방식**: 1차원 수평 이동 (X축 좌/우 이동만 지원, Y축 좌표는 화면 최하단 고정)
* **이동 속도**: 표준 150 px/sec (화면 가로 해상도 224px 기준 약 1.5초 만에 횡단 가능)
* **화면 제한 (Clamp)**: 화면 좌우 경계(Border)를 벗어날 수 없음
* **잔기 (Lives)**:
  * 게임 시작 시 기본 3기 제공 (현재 플레이 기체 1기 + 대기 2기).
  * 기체 피격 시 잔기 1 감소 후 화면 중앙 하단에서 재출격.
  * 잔기가 0인 상태에서 피격 시 게임 오버(Game Over).
* **무적 판정 (Respawn Invincibility)**:
  * 사망 후 리스폰 시 약 1.5초간 깜빡이며 무적 상태 유지.
  * 무적 시간 동안 사격 및 이동 가능.

### 1.2 미사일 발사 메커니즘 (Shooting Engine)
* **발사 키**: 단일 공격 버튼 (Space / Key Z / Gamepad A 등)
* **탄환 수 제한 (Screen Bullet Limit)**:
  * **싱글 파이터**: 화면 내 최대 **2발** 동시 존재 가능.
  * **듀얼 파이터**: 화면 내 최대 **4발** (2발 x 2열) 동시 존재 가능.
* **탄환 속도**: 약 400 px/sec (수직 상향 직선 이동).
* **탄환 소멸 조건**:
  1. 적 기체 충돌 판정 발생 시 (적 체력 차감 및 탄환 소멸).
  2. 화면 최상단 Y좌표 초과 시.
  3. 특정 적(보스 실드 등)의 방어 판정 시.

## 2. 포획 및 듀얼 파이터 시스템 (Capture & Dual Fighter)

갤러그의 가장 핵심적이고 독창적인 시스템 메커니즘입니다.

```
[ 싱글 파이터 ] ───(트랙터 빔 피격)───> [ 기체 포획 (잔기 1 소모) ]
                                                   │
                                                   ▼
[ 차기 파이터 출격 ] ◄───────────────── [ 보스 상단에 적 포획기 결속 ]
         │
         ├───────────────────────────────────────────────┐
         │ (보스가 포획기를 대동하고 급강하 비행 시)     │ (보스가 상단 편대에 대기 중일 때)
         ▼                                               ▼
[ 비행 중인 보스 격파 ]                          [ 대기 중인 보스 격파 ]
         │                                               │
         ▼                                               ▼
[ 포획기 해방 및 자유 회전 하강 ]                [ 포획기가 적으로 변환되어 급강하 ]
         │                                               │
         ▼                                               ▼
[ 플레이어 기체와 좌우 도킹 ]                    [ 격파 시 1,000점 (구출 실패) ]
         │
         ▼
[ ★ 듀얼 파이터 완성 ★ ]
```

### 2.1 포획 메커니즘 (Capture Sequence)
1. **발동 조건**: 보스 갤러그(Boss Galaga)가 화면 중간 고도까지 단독 다이브한 뒤 정지하여 하단으로 파란색 트랙터 빔(Tractor Beam)을 방출.
2. **피격 판정**: 플레이어 기체가 트랙터 빔 영역 내로 진입 시 포획 시퀀스 트리거.
3. **포획 연출**:
   * 플레이어 조작권 상실.
   * 기체가 회전 애니메이션과 함께 빔을 따라 보스 갤러그 상단으로 견인.
   * 기체 색상이 아군 색상(흰/빨)에서 포획 상태 색상(빨/청)으로 반전.
   * 보스 갤러그와 함께 상단 편대로 복귀하여 편대 최상단에 결속.
4. **잔기 처리**:
   * 잔여 기체가 1대 이상 남아있을 경우: 포획 완료 즉시 다음 기체가 하단에서 출격.
   * 잔여 기체가 0대인 경우: 포획 완료 즉시 게임 오버.

### 2.2 구출 및 듀얼 파이터 결합 (Rescue & Docking)
포획된 기체를 구출하는 방식에 따라 3가지 분기가 발생합니다:

| 분기 상황 | 처리 내용 및 결과 | 판정 |
| :--- | :--- | :---: |
| **Case 1: 비행 중 보스 격파** | 보스가 포획기를 대동하고 화면 아래로 급강하 비행할 때 보스를 격파.<br>→ 포획기가 회전하며 천천히 수직 하강.<br>→ 플레이어 기체가 포획기에 접촉하면 좌/우로 자동 도킹하여 **듀얼 파이터**로 변신. | **O (성공)** |
| **Case 2: 대기 중 보스 격파** | 상단 편대에 머무르고 있는 보스를 격파.<br>→ 포획기가 적으로 돌아서서 플레이어를 향해 1회 자폭 급강하 후 화면 이탈.<br>→ 격파 시 1,000점 획득 (구출 불가). | **X (실패)** |
| **Case 3: 포획기 오인 사격** | 보스를 맞추지 못하고 결속된 포획 기체를 직접 사격.<br>→ 포획 기체 파괴 (1,000점 획득, 구출 실패). | **X (실패)** |

### 2.3 듀얼 파이터의 특성 및 피격 판정
* **화력**: 1회 사격 시 좌우 포대에서 2발 동시 발사 (화면 내 최대 4발).
* **히트박스**:
  * 단일 기체 대비 좌우 피격 너비가 2배로 확장.
  * 좌측 기체 피격 시: 좌측 기체 파괴, 우측 기체는 싱글 파이터로 전환되어 계속 플레이.
  * 우측 기체 피격 시: 우측 기체 파괴, 좌측 기체는 싱글 파이터로 전환되어 계속 플레이.
  * 두 기체 중앙 경계면에 대형 폭발/충돌 발생 시: 2기 동시 파괴 (잔기 1 차감 후 싱글 리스폰).
* **트랙터 빔 재포획**: 듀얼 파이터 상태에서 트랙터 빔에 맞으면 1기만 포획되고 나머지 1기는 즉시 싱글 파이터로 유지되어 계속 조작 가능.

## 3. 점수 산정 및 보상 시스템 (Scoring & Extends)

### 3.1 적 격파 점수 테이블 (Score Table)

| 적 기체 유형 | 편대 대기 상태 격파 | 비행/강하 상태 격파 | 특수 조건 점수 |
| :--- | :---: | :---: | :--- |
| **자코 (Zako - 청색)** | 50점 | 100점 | - |
| **고에이 (Goei - 적색)** | 80점 | 160점 | - |
| **보스 갤러그 (Boss Galaga - 녹색/황색)** | 150점 | - | • 단독 비행 중 격파: 400점<br>• 호위기 1대 동반 격파: 800점<br>• 호위기 2대 동반 격파: 1,600점 |
| **변신 적 (Transform Enemy)** | 100점 | 200점 | 3기 편대 전멸 시 1,000점 ~ 3,000점 보너스 |
| **포획된 파이터 격파** | - | 1,000점 | 적 상태일 때 격파 시 |

### 3.2 챌린징 스테이지 점수 산정 (Challenging Stage Scoring)
* **기본 격파 점수**: 기당 100점 (총 40기 = 최대 4,000점)
* **스페셜 보너스 (전멸 시)**:
  * 격파 수 < 40기: 격파 수 x 100점 보너스
  * 40기 완파 (PERFECT): **10,000점** 특별 보너스 지급

### 3.3 익스텐드 (보너스 잔기 획득) 규칙
* **1차 익스텐드**: **20,000점** 도달 시 잔기 +1
* **2차 익스텐드**: **70,000점** 도달 시 잔기 +1
* **이후 반복**: 매 **70,000점** 추가 획득 시마다 잔기 +1 (설정에 따라 1회만 제공하도록 조정 가능)
