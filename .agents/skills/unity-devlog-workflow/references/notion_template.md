## 2. 페이지 생성 및 초안 작성 규칙

1. **당일 일지 생성**:
   - 작업 시작 시 `API-post-search` (query: `[YYYY-MM-DD] 작업 기록`)로 오늘 날짜의 일지가 존재하는지 확인.
   - **존재하지 않을 때만** `API-post-page`를 호출하여 생성.
2. **초안 미작성 원칙**:
   - ⚠️ **에이전트는 본문(초안)을 작성하지 않고 빈 페이지로 둡니다.**
   - 사용자가 직접 자신의 언어로 학습 및 개발 일지를 작성할 수 있도록 합니다.

### 빈 페이지 생성 API 호출 예시
```json
{
  "parent": {
    "database_id": "13cc49b1-3a07-814e-b7b5-cf14b64ca1ee"
  },
  "properties": {
    "Name": {
      "title": [
        {
          "text": {
            "content": "[2026-08-14] 작업 기록"
          }
        }
      ]
    },
    "Date": {
      "date": {
        "start": "2026-08-14"
      }
    },
    "분류": {
      "select": {
        "name": "일지"
      }
    }
  }
}
```

## 3. 작업 종료 시 일지 검토 및 피드백 규칙

### 트리거 조건
- 사용자가 "작업 종료", "수고하셨습니다", "오늘 작업 마무리", "종료할게요" 등을 입력하거나 세션이 마감될 때.

### 비교 및 처리 절차
1. **페이지 본문 조회**:
   - `API-retrieve-page-markdown` (또는 `API-get-block-children`)으로 당일 일지 페이지 본문 확인.
2. **상태별 대응**:
   - **Case A: 본문이 비어있는 경우 (3-1)**
     - 사용자에게 오늘 진행한 작업 내역을 바탕으로 일지 작성을 권유합니다.
     - 사용자가 "일지 작성 완료했다"고 응답하거나, 일지 페이지 본문이 채워질 때까지 체크 및 대기합니다.
     - 일지 작성이 확인되면 즉시 **Case B**로 넘어갑니다.
   - **Case B: 본문 내용이 작성되어 있는 경우 (3-2)**
     - 당일 Git 커밋 내역(`git log --since="today"`), 변경된 스크립트/에셋과 일지 내용을 비교합니다.
     - 주요 변경점 중 누락된 부분이나 보완하면 좋을 기술 포인트가 있다면 Notion 페이지 하단에 **Toggle(토글 블록)**으로 1회 피드백을 첨부합니다.

## 4. 피드백 토글(Toggle) 블록 작성 형식

### Notion API 블록 추가 예시 (`API-patch-block-children`)
```json
{
  "block_id": "<PAGE_ID>",
  "children": [
    {
      "object": "block",
      "type": "toggle",
      "toggle": {
        "rich_text": [
          {
            "type": "text",
            "text": {
              "content": "💡 에이전트 작업 비교 피드백 (2026-08-14)"
            }
          }
        ],
        "children": [
          {
            "object": "block",
            "type": "paragraph",
            "paragraph": {
              "rich_text": [
                {
                  "type": "text",
                  "text": {
                    "content": "오늘 Git 커밋된 PlayerController 점프 로직 변경사항과 Rigidbody 파라미터 튜닝 내역이 잘 정리되어 있습니다. 추가로 LayerMask(GroundCheck) 설정 부분도 함께 메모해두시면 추후 재참조 시 유용할 것 같습니다."
                  }
                }
              ]
            }
          }
        ]
      }
    }
  }
}
```

### 피드백 제한 규칙
- 사용자의 명시적 재요청이 없는 한 **1회만** 피드백을 등록합니다.
- 이미 페이지 본문에 `에이전트 작업 비교 피드백` 토글이 존재하면 추가 작성을 건너뜁니다.
