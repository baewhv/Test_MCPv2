# GitHub Issue 점검 및 작업 목록 동기화 워크플로우

이 스킬은 PM 에이전트가 "이슈 체크해줘" 명령 또는 일일 작업 마감("작업 마칠게/퇴근") 시점에 GitHub Issues를 전수 점검하여, 이슈의 생명주기를 정리하고 승인된 항목을 `worklist.md`에 반영하는 절차를 정의합니다.

---

## 1. 이슈 상태별 4대 처리 규칙

1. **`[반려]` 태그 항목 (Open 상태)**:
   - 미채택/반려된 항목이므로 즉시 **Close (state: closed)** 처리합니다.
2. **`[수락]` 태그 항목**:
   - 사용자가 승인한 항목이므로 제목 태그를 **`[착수]`**로 변경합니다 (`[AI_*][착수] ...`).
   - `docs/work/worklist.md`의 `## 사용자 최우선 지시사항` 섹션에 `- [ ] [태스크명] (Issue #nn)`로 자동 등록합니다.
3. **`[완료]` 태그 항목 (Open 상태)**:
   - 개발 및 QA 검수가 완료된 항목이므로 즉시 **Close (state: closed)** 처리합니다.
4. **`[제안]` 태그 항목 (Open 상태)**:
   - 사용자의 확인/승인이 필요한 대기 상태이므로 개수를 파악하여 **"확인해야 할 이슈(제안)가 N건 있습니다."** 알림과 함께 이슈 목록을 보고합니다.

---

## 2. 원클릭 자동 실행 스크립트

PM은 아래 명령어를 실행하여 이슈 전수 점검 및 동기화를 즉시 완결할 수 있습니다:
```bash
node .agents/skills/github-issue-sync/scripts/sync_issues.js
```

---

## 3. 사용자 보고 양식

동기화 완료 후 사용자에게 아래 양식으로 결과를 요약 보고합니다:

```markdown
### GitHub Issue 점검 및 동기화 결과 보고

| 구분 | 처리 건수 | 상세 내역 |
| :--- | :--- | :--- |
| **[반려] Close** | N건 | #nn [반려] ... |
| **[수락 ➔ 착수]** | N건 | #nn [착수] ... (worklist 최우선 지시사항 등록 완료) |
| **[완료] Close** | N건 | #nn [완료] ... |
| **[제안] 대기** | **N건** | ⚠️ 확인해야 할 제안 이슈가 N건 있습니다. |

- **미결 제안 목록**:
  1. #nn: [AI_designer][제안] ...
  2. #nn: [AI_developer][제안] ...
```
